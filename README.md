# Bai 1: Hello Cloud

API Express chay trong GitHub Codespaces va trang ket qua phuc vu bai thuc hanh.

## Chay ung dung

Yeu cau Node.js 18 tro len.

```sh
npm install
npm start
```

Mo `http://localhost:3000/`; endpoint tra ve thong tin runtime cua may dang chay.
Codespaces se tu chuyen tiep cong 3000 theo cau hinh trong `.devcontainer`.

## Hoan thien bai nop

- Cap nhat bang trong `docs/index.html` bang thoi gian va thong so may tinh cua ban va Codespace. Khong de lai cac o `[dien ...]`.
- Thu URL cong khai tren thiet bi khac, sau do chuyen Port Visibility ve Private.
- Bat GitHub Pages tu nhanh `main`, thu muc `/docs`; nop link repo, link trang va anh Billing Usage.
- Dung Codespace sau khi hoan tat de tranh phat sinh su dung them.

Trang ket qua co san khung 5 dac tinh NIST, ghep voi thao tac tuong ung trong bai lab.
